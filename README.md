# BLACK//LAB — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Project structure

- `index.html` — page content and sections
- `css/styles.css` — layout, responsive rules, visual effects, and card interactions
- `js/script.js` — navigation, reveal effects, contact form, and holographic cursor
- `assets/images/` — visual assets used by the page

## Run locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Contact form

The form validates the fields and opens the visitor's email application with a prepared message addressed to the portfolio owner. It does not send messages through a server.

## Publishing

The site can be deployed as a static website using Netlify, GitHub Pages, or another static hosting provider. Before publishing, verify all project descriptions and add real profile links where desired.

## Notes

- The page content is in English.
- The layout includes responsive adjustments for mobile, tablet, and desktop screens.
- Project cards include pointer-based tilt effects on desktop and touch feedback on mobile.
- The Tools card lists Microsoft Excel only.
